3. INSTRUCCIONES RÁPIDAS PARA EJECUTAR EN LOCAL
--------------------------------------------------------------------------------
Requisitos previos: Node.js v20+ instalado.

PASO 1: LEVANTAR EL SERVIDOR BACKEND (API RESTful)
   1. Abrir una terminal en la carpeta 'backend/':
      cd backend
   2. Instalar dependencias:
      npm install
   3. Iniciar el servidor:
      npm run dev
   -> La API quedará activa en: http://localhost:3001/api/v1
   -> Documentación Swagger disponible en: http://localhost:3001/api/docs

PASO 2: LEVANTAR LA APLICACIÓN CLIENTE (EXPO / REACT NATIVE)
   1. En otra terminal, ubicarse en la raíz del proyecto ('barrio-front/'):
      npm install
   2. Iniciar la aplicación:
      npx expo start
   3. Opciones de visualización:
      - Presionar la tecla 'w' para abrirlo inmediatamente en el Navegador Web (PC).
      - O escanear el código QR con la app gratuita 'Expo Go' desde un celular Android/iOS.

4. INSTRUCCIONES PARA PROBAR EL APK EN ANDROID
--------------------------------------------------------------------------------
- El archivo 'Barrio.apk' adjunto en esta carpeta puede ser instalado directamente
  en cualquier dispositivo Android habilitando la opción "Instalar aplicaciones de
  fuentes desconocidas".
- El APK se conecta automáticamente a la infraestructura en la nube (Supabase Auth,
  PostgreSQL y Supabase Realtime). Para comunicarse con el backend local de pruebas,
  el dispositivo debe encontrarse en la misma red local o bien ejecutar la versión web.
